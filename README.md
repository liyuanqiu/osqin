# OpenSourceQin (OSQIN)

开源秦殇 - A tribute to the classic game "Prince of Qin" (《秦殇》)

## 项目简介 (Project Overview)

OpenSourceQin (暂定名) 是一个致敬经典游戏《秦殇》、《天骄》和《秦殇世界》的开源 MMORPG 项目。本项目旨在复刻并传承这些经典游戏的玩法精髓，打造一个基于"五行相生相克"核心机制的大型多人在线角色扮演游戏。

OpenSourceQin is an open-source MMORPG project paying tribute to classic games like "Prince of Qin", "The Prowess of Wat", and "Prince of Qin World". This project aims to recreate and inherit the essence of these classic games, building a massively multiplayer online role-playing game based on the core mechanism of the "Five Elements" (Wu Xing).

## 核心特色 (Key Features)

- **五行相生相克系统**: 游戏的核心战斗机制基于中国传统五行理论（金、木、水、火、土）
- **MMORPG 体验**: 持久化的多人在线世界，支持玩家交互、组队协作与自由交易
- **经典 ARPG 玩法**: 融合暗黑类 Diablo-like 元素的战斗体验
- **秦末历史背景**: 以秦朝末年楚汉相争的历史时期为舞台
